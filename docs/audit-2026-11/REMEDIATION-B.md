Note on B-01 consistency: Home and Progress (UI owned by other stages) date every run in the device
zone, including runs whose source recorded an offset. For runs recorded in the device's own zone the
results are identical. A run imported with a different recorded offset (for example recorded while
travelling) is dated by its own offset in Calendar/History/review and by the device zone on
Home/Progress. Passing `ActivityDates::localDate` into those screens' `dateAt`/`dateOf` functions
would make that last case identical too (reported to the integrating stage).
