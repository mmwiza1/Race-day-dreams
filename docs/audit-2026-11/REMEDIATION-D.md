# Stage D navigation, onboarding, accessibility

Post-audit hardening for area C of the November 2026 audit
([C-navigation-ux-a11y.md](C-navigation-ux-a11y.md), [summary](../AUDIT_2026-11.md)).
Branch `ccr-60f602a7-tfmok3-hard-d`, based on `ccr-60f602a7-tfmok3-audit` (main aa6fa233 plus the
audit documents).

**Local verification here means compilation, formatting (`format-code.py --check`) and `:app:lintDebug` (passed on the final tree).** There is no emulator in this environment, so
every regression test below is an instrumented (androidTest) test that compiles locally and runs
in CI. `sharedUi/src/iosMain` and `iosApp` were not compiled; the only iOS-visible changes are in
`commonMain` (default parameters, the shared navigation bar labels and the recovery disclosure
labels), which compile for Android.

**Galaxy S24 goal selection (C-R01): still awaiting physical-device verification.** The C-01 and
C-02 fixes remove the strongest code-level explanations, but the owner's report is not resolved
until the revised interaction has been retested on the physical Galaxy S24.
